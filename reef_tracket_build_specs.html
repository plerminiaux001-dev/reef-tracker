Project Overview

Your Complete Reef Aquarium Management Suite

A web-based dashboard designed for reef aquarium enthusiasts. It provides a centralized platform to track vital water parameters, calculate complex dosing schedules, and manage saltwater mixing with precision and ease.

Technical Architecture

Built with a lightweight, framework-free approach prioritizing performance and simplicity.

🎨

Frontend

HTML5 & CSS3 with a modern responsive layout utilizing glassmorphism design principles.

⚡

Logic

Vanilla JavaScript. Consolidated architecture with absolutely zero heavy framework dependencies.

📈

Visualization

Chart.js implementation for highly interactive and dynamic parameter trend visualizations.

☁️

Backend & Deploy

Google Apps Script for cloud data persistence. Deployed continuously via Netlify on push.
